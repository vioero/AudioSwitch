# AudioSwitch 使用说明
## 一个可以自由切换麦克风和音频播放设备的 Windows 小工具

---

## 一、软件简介

AudioSwitch 是一个**体积小巧、界面美观**的 Windows 桌面工具，帮你**一键切换默认麦克风和音箱**，不用再钻进 Windows 设置里层层点击。

版本：**1.1.0**（2026）

---

## 二、运行要求

- 操作系统：Windows 11（兼容 Windows 10）
- **首次使用需安装 .NET 8 运行时**（见下方"首次安装指引"）

---

## 三、首次安装指引（重要）

本软件是"框架依赖"版本，exe 很小（不到 1 MB），但**第一次使用前**需要电脑装有 .NET 8 运行时。

### 怎么判断需不需要装？

1. 直接双击 `AudioSwitch.exe`；
2. 如果能正常打开窗口 → 说明电脑已装好 .NET 8，跳过下面步骤；
3. 如果弹出报错窗口（提示缺少 .NET）→ 需要安装。

### 如何安装 .NET 8 运行时？

1. 打开浏览器，访问微软官方下载页：**https://dotnet.microsoft.com/download/dotnet/8.0**
2. 找到 **".NET Desktop Runtime 8.x（Windows x64）"** 那一栏，点击下载；
3. 双击下载好的安装包，一路"下一步"完成安装（约 60MB，装一次即可）；
4. 重新双击 `AudioSwitch.exe`，即可正常使用。

> 说明：.NET 运行时是微软官方组件，很多软件都依赖它，装一次以后所有 .NET 软件通用，安全无害。

## 四、基本使用

### 1. 切换设备（主窗口）
- 打开软件后，主窗口顶部是 **"麦克风 / 音箱" 两个分段按钮**，各自显示该类设备**当前正在使用的默认设备名**，两边现状一屏可见；
- 点选一个角色（如"麦克风"），下方列表展示该角色的全部设备，**点击**某个设备，它就会变成 Windows 默认设备；
- 当前默认设备**蓝色高亮并置顶**显示，一眼就能找到。

### 2. 系统托盘
- 点窗口右上角 **X**，软件**不会退出**，而是缩到任务栏右下角的**托盘**（蓝色圆点图标）；
- **右键**托盘图标 → 弹出与主窗口同风格的**设备面板**：上方"麦克风"区、下方"音箱"区，当前默认设备带标记，点击即切换；面板底部有"打开主窗口"和"退出"；
- **双击**托盘图标 → 重新打开主窗口；
- 在别处点一下鼠标，托盘面板会自动收起。

### 3. 全局快捷键（任何软件里都能用）
| 快捷键 | 作用 |
|---|---|
| `Ctrl + Alt + F9` | 切换到下一个麦克风 |
| `Ctrl + Alt + F10` | 切换到下一个音箱 |

> 快捷键是"循环切换"：连续按，会在你的设备之间轮流切换。

### 4. 开机自启动
- 主窗口底部有 **"开机自动启动"** 勾选框；
- 勾选后，软件会随 Windows 开机自动启动（藏在托盘里）；
- 取消勾选则不再自动启动。

### 5. 设置面板
- 主窗口右下角 **"设置"** 按钮 → 右侧滑出设置面板，可设置：
  - **切换快捷键**：麦克风 / 音箱各自的循环切换快捷键；
  - **主题模式**：浅色 / 深色 / 跟随系统；
  - **设备显示范围**：智能 / 全部 / 仅 USB 和蓝牙；
  - **关闭行为**：询问 / 最小化到托盘 / 直接退出；
- 所有设置即时生效并自动保存。

## 五、常见问题

**Q：点 X 后软件去哪了？**
A：没退出，缩到右下角托盘了（蓝色圆点）。右键托盘图标选"退出"才是真正关闭。

**Q：为什么有些设备没显示？**
A：默认会显示全部已启用的设备，未插入（离线）的设备同样列出并显示为不可选，方便设备回来后直接切回；已停用的设备需先在 Windows 设置里启用。

**Q：快捷键没反应？**
A：可能是 `Ctrl+Alt+F9` 被其他软件占用了。快捷键可在"设置"面板中自定义（默认麦克风 `Ctrl+Alt+F9`、音箱 `Ctrl+Alt+F10`）；若被占用，程序会提示注册失败。

**Q：为什么 exe 这么小？**
A：这是"框架依赖"打包方式，把公共组件（.NET 运行时）交给系统统一管理，所以本体很小。

## 六、卸载方法

本软件提供两种使用方式：

**绿色版（免安装）：**
1. 右键托盘图标选"退出"；
2. 删除 `AudioSwitch.exe` 文件即可。

**安装版：**
从 Windows 设置 → 应用 → 卸载 AudioSwitch（会同时清理开机自启项）。

两种方式都不会在系统里留下其他垃圾。

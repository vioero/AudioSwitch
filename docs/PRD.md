# 软件需求文档（PRD）
## 项目名称：AudioSwitch（暂定名）
> 一个可以自由切换麦克风设备和音频播放设备的 Windows 桌面小工具

---

## 1. 项目背景与目标

### 1.1 背景
Windows 11 自带的音频管理存在"不对称"的体验：
- **音频输出（播放设备）**：已经很好用，右下角图标一点就能切换，还能单独控制每个软件/网页的音量。
- **麦克风（输入设备）**：切换非常麻烦，必须钻进"设置"里一层层点，不自由、不快捷。

对于同时拥有多套麦克风设备的用户（耳机麦、USB 麦、蓝牙麦、虚拟麦等），频繁切换麦克风是一件很痛苦的事。

### 1.2 目标
做一个**体积小巧、免安装、界面美观（贴合 Win11 风格）** 的 Windows 桌面工具，让用户可以**一键 / 快捷键**自由切换麦克风设备和音频输出设备。

### 1.3 一句话描述
> "让切换麦克风和音箱，像点一下鼠标那么简单。"

---

## 2. 用户群体

| 类型 | 描述 | 优先级 |
|---|---|---|
| 核心用户 | 拥有多个麦克风设备、需要频繁切换的普通用户（如：语音聊天、直播、录音、开会） | 高 |
| 主要用户 | 追求 Windows 11 美观界面、喜欢轻量免安装工具的"效率党" | 中 |
| 潜在用户 | 所有被 Windows 原生麦克风切换困扰的用户 | 中 |

> 本项目第一阶段以"自己用 + 身边的同类需求用户"为主，先做出真正好用的东西，再考虑大规模推广。

---

## 3. 核心功能（MVP，第一版必须做）

### 3.1 麦克风设备切换 ⭐（本项目核心）
- 自动列出电脑上所有**输入设备（麦克风）**：2.4G 耳机麦、USB 麦、蓝牙麦、虚拟麦等。
- 用户点击即可切换**当前默认麦克风**。
- 支持**全局快捷键**切换（无需打开窗口）。
- 切换后能立即生效。

### 3.2 音频输出设备切换
- 自动列出所有**输出设备（播放设备）**：音箱、耳机、蓝牙耳机等。
- 用户点击即可切换**当前默认输出设备**。
- 支持全局快捷键切换。

### 3.3 系统托盘常驻
- 软件最小化后收在**任务栏右下角的托盘**里，不占屏幕。
- 托盘图标上右键，就能直接看到设备列表并快速切换（类似 Win11 右下角音量面板的体验）。

### 3.4 开机自启动（可开关）⭐（用户明确要求）
- 提供一个**开关**，用户可自由选择是否开机自动启动。
- 默认关闭，由用户手动打开。

### 3.5 免安装、体积小巧 ⭐（用户明确要求）
- 打包成**单个 exe**，双击直接运行，**不需要安装**。
- 体积尽量小（目标：几 MB 级别），后台占用资源极低。

### 3.6 界面美观、贴合 Win11 风格 ⭐（用户明确要求）
- 使用 Windows 11 的**现代化设计语言**（圆角、毛玻璃/亚克力、流畅动画）。
- 界面简洁高级，不花哨。

## 4. 次要功能（第一版可以做，但非必须）

- 设备切换后的**提示通知**（气泡/小动画）。
- 可自定义快捷键组合。
- 记住上次使用的设备，开机时自动恢复。
- 隐藏不常用的设备（避免列表太长）。
- 中文界面（可留英文扩展）。

---

## 5. 后续扩展功能（未来版本，现在不做）

- **按软件单独路由声音**：某个软件的麦克风固定用 A，另一个用 B（类似 EarTrumpet 的高级功能）。
- 每个设备的**独立音量控制**。
- 设备热插拔自动切换（拔掉耳机自动切回音箱）。
- 多语言支持（中/英）。
- 更多皮肤/主题。

> 这些功能先记下来，**第一版绝不做**，避免项目失控。

## 6. 使用场景

| 场景 | 用户行为 |
|---|---|
| 语音聊天中，从耳机麦切换到 USB 专业麦 | 按下快捷键，麦克风立刻切过去 |
| 开会前想用蓝牙麦，开完会切回耳机麦 | 点一下托盘图标，选麦克风 |
| 插上音箱想听歌，拔出想用耳机 | 一键切换输出设备 |
| 直播 / 录音时在多个麦克风之间来回切 | 快捷键快速切换，不打断流程 |

---

## 7. 非目标（明确不做，防止跑偏）

- 不做音频的**处理/变声/混音**功能（那是 VoiceMeeter 的领域）。
- 不做复杂的**录音/播放**功能。
- 第一版不做**按软件路由**（留给未来）。
- 不做手机 App / 网页版，只做 Windows 桌面工具。

---

## 8. 成功标准（怎么算"做成了"）

1. 双击 exe 即可运行，无需安装。
2. 能在一秒内完成一次麦克风切换（点击或快捷键）。
3. 界面看起来像 Windows 11 原生应用（高级、不廉价）。
4. 后台运行时内存占用低、不卡顿。
5. 开机自启动开关好用、可正常关闭。
6. 在 Win11 上稳定运行，不崩溃。

---

## 9. 市场调研结论（已记录）

市面上已有同类软件：**SoundSwitch**（开源、功能全）、EarTrumpet（侧重输出）、Audio Switcher、MicRouteSwitch 等。

**结论**：
- 功能上 SoundSwitch 已基本满足需求，但**界面不美观**，不符合"Win11 高级风"的要求。
- 本项目最大的差异化价值 = **更美观的界面 + 更小巧 + 免安装 + 专注核心体验**。
- SoundSwitch 是开源项目，可作为**技术参考**（尤其"如何切换设备"这一底层难题）。

### B5 实测问题修复（用户走查发现，按严重度排序）

- [x] **B8【P0】修复托盘菜单选择任何选项导致软件整体卡死** —— 根因：`TrayMenuWindow.Close()` 执行期间窗口销毁触发 `Deactivated`，处理器再次调用 `Close()` 重入，WPF `VerifyNotClosing()` 抛异常中断销毁流程，UI 线程永久卡死。插桩构建实测复现并定位（日志停在 `Activate before Close` → `Deactivated` 后再无输出）；修复为统一 `CloseMenu()` 入口（`_isClosing` 标志 + 退订 Deactivated + try/catch 三重防护），修复后实测 `Closed fired → Activate after Close` 正常返回（约 1.5 小时）
- [x] **B9 修复托盘菜单深色模式"打开主窗口"文字不可见** —— `TrayActionStyle` 未设 `Foreground`，回退系统默认黑色。补 `{DynamicResource TextPrimary}` 主题色；“退出”保持显式红色不变（按用户要求）（约 10 分钟）
- [x] **B10 修复热键循环切换顺序** —— 循环读的是"默认设备置顶"的展示顺序，当前设备恒在第一位，切换只在第一、二项间振荡、永远轮不到第三个设备。`DeviceService` 增存系统枚举顺序副本（`MicrophonesEnumOrder`/`SpeakersEnumOrder`），循环改按枚举顺序向下轮转、末位回绕（约 40 分钟）
- [x] **B11 修复"开机自启动"开关点击范围过大** —— `ToggleStyle` 模板 `ContentPresenter` 在 `*` 列拉伸，文字右侧整片空白都能点亮开关。按用户要求（只有图标可点）为 ContentPresenter 设 `IsHitTestVisible="False"`（约 10 分钟）
- [x] **B12 修复设置保存整体失败（潜伏 bug，日志实证）** —— 日志显示每次保存设置都报 JSON 序列化 Infinity 失败：窗口隐藏/最小化时 `Left/Top/RestoreBounds` 可能为 NaN，写入后**整个设置保存链报废**（快捷键/主题修改全部无法落盘）。`SaveWindowPosition` 增加有限性校验，非有限值不写入（约 20 分钟）

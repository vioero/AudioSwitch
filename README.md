# AudioSwitch

> 一款轻量、美观的 Windows 音频设备切换工具

---

## 简介

AudioSwitch 是一款专为 Windows 用户设计的音频设备快速切换工具。它解决了 Windows 系统中**麦克风切换操作繁琐**的痛点——原本需要层层点击"设置"才能完成的操作，现在**一键或一个快捷键**就能搞定。

**一句话介绍**：让切换麦克风和音箱，像点一下鼠标那么简单。

---

## 为什么需要 AudioSwitch？

Windows 11 的音频管理有一个"不对称"的设计：
- **音频输出（播放设备）**：已经很好用，右下角图标一点就能切换。
- **麦克风（输入设备）**：切换非常麻烦，必须钻进"设置"里一层层点。

对于同时拥有多套麦克风设备的用户（耳机麦、USB 麦、蓝牙麦、虚拟麦等），频繁切换麦克风是一件很痛苦的事。AudioSwitch 就是为了解决这个问题而生的。

---

## 核心功能

### 🎤 一键切换麦克风
- 自动列出电脑上所有输入设备（2.4G 耳机麦、USB 麦、蓝牙麦、虚拟麦等）
- 点击即可切换当前默认麦克风
- 支持**全局快捷键**切换（默认 Ctrl+Alt+F9），无需打开窗口

### 🔊 一键切换音频输出
- 自动列出所有输出设备（音箱、耳机、蓝牙耳机等）
- 点击即可切换当前默认输出设备
- 支持**全局快捷键**切换（默认 Ctrl+Alt+F10）

### 🖥️ 系统托盘常驻
- 最小化后收在任务栏右下角托盘，不占屏幕
- 右键托盘图标即可看到设备列表，直接切换
- 托盘菜单显示当前默认设备名，一目了然

### 🎯 智能设备过滤
- **智能模式**：显示全部真实设备（含板载声卡），仅排除虚拟声卡、显卡音频输出、混音回环等杂项
- **全部模式**：显示所有设备
- **USB/蓝牙模式**：只显示外部连接的设备

### ⚡ 开机自启动
- 提供开关，用户可自由选择是否开机自动启动
- 默认关闭，由用户手动打开

### ⌨️ 自定义快捷键
- 支持自定义麦克风和音箱的切换快捷键
- 支持 Ctrl、Alt、Shift、Win 等组合键

### 🌙 深色模式
- 支持浅色/深色/跟随系统三种主题模式
- 深色模式下文字对比度优化，清晰易读

### 💾 窗口位置记忆
- 记住窗口的位置和大小
- 下次打开时自动恢复到上次的位置

## 界面特色

- **Win11 风格设计**：圆角卡片、渐变背景、柔和阴影
- **自定义标题栏**：无边框窗口 + 自定义最小化/最大化/关闭按钮（保留系统原生拖拽缩放）
- **分段控制器**：顶部"麦克风 / 音箱"两个角色段，各自显示当前默认设备，两边现状一屏可见
- **单列设备列表**：点击即切换，当前默认设备高亮并置顶
- **同风格托盘面板**：右键托盘弹出无边框圆角面板，麦克风/音箱分区展示，点外部自动收起
- **流畅动画**：按钮 hover 放大、按下回弹、卡片浮起效果（自动尊重系统"减少动画"）
- **现代滑动开关**：Win11 风格的开关控件，替代传统复选框
- **精致滚动条**：细条圆角滚动条，hover 变色
- **设置抽屉**：右侧滑入的设置面板，带半透明遮罩
- **主题三态**：浅色 / 深色 / 跟随系统，设计令牌整字典切换

## 技术架构

### 技术栈
- **语言**：C# + WPF + .NET 8.0
- **音频 API**：NAudio 2.2.1
- **设备切换**：COM 接口 IPolicyConfig
- **托盘**：NotifyIcon 图标 + WPF 无边框弹出面板（TrayMenuWindow）
- **主题**：设计令牌字典（Themes/ 浅/深两套）整字典切换，SystemThemeWatcher 跟随系统

### 项目结构
```
AudioSwitch/
├── Core/
│   └── DeviceSwitcher.cs      # 设备切换核心（COM 调用）
├── Models/
│   ├── AudioDevice.cs         # 设备数据模型
│   ├── DeviceKind.cs          # 设备分类枚举（USB/蓝牙/板载…）
│   └── DeviceRowItem.cs       # 列表行视图模型
├── Services/                  # 11 个独立 Service
│   ├── DeviceService.cs       # 设备枚举、过滤、缓存
│   ├── ThemeService.cs        # 主题切换（整字典替换）
│   ├── SystemThemeWatcher.cs  # 跟随系统深浅色变化
│   ├── TrayService.cs         # 托盘图标、菜单管理
│   ├── HotkeyManager.cs       # 快捷键管理（注册/失败回滚）
│   ├── HotkeyService.cs       # Win32 热键 API
│   ├── SettingsPanelManager.cs# 设置面板（抽屉）管理
│   ├── SettingsManager.cs     # 设置读写（JSON）
│   ├── AutoStartService.cs    # 开机自启动
│   ├── Logger.cs              # 日志记录
│   └── MotionService.cs       # 动画调度（尊重"减少动画"）
├── Themes/                    # 设计令牌字典（浅/深两套 + 控件/字体）
│   ├── Colors.Light.xaml      # 浅色令牌
│   ├── Colors.Dark.xaml       # 深色令牌
│   ├── Controls.xaml          # 控件样式
│   └── Typography.xaml        # 字体样式
├── Assets/                    # 应用图标
├── MainWindow.xaml / .cs      # 主窗口（分段控制器 + 单列设备列表）
├── TrayMenuWindow.xaml / .cs  # 托盘弹出面板（无边框、四缘定位）
├── ClosePromptWindow.xaml     # 关闭确认对话框
└── App.xaml / .cs             # 单实例启动
```

### 设计原则
- **模块化**：每个 Service 负责一个独立功能，互不干扰
- **按需刷新**：设备列表只在用户操作时刷新，避免无谓的 UI 闪烁
- **后台加载**：设备枚举在后台线程执行，不阻塞 UI
- **设备缓存**：设备元数据（名称、总线类型）缓存复用，减少 COM 调用

## 使用方法

### 基本操作
1. 双击 `AudioSwitch.exe` 启动（免安装）
2. 主窗口顶部选择角色（麦克风 / 音箱），各自显示当前默认设备
3. 下方列表中点击设备即可切换默认设备（当前设备高亮置顶）
4. 点击 X 按钮最小化到托盘，继续后台运行

### 快捷键
- **Ctrl + Alt + F9**：切换到下一个麦克风
- **Ctrl + Alt + F10**：切换到下一个音箱
- 快捷键可在设置中自定义

### 托盘菜单
- 右键托盘图标，弹出与主窗口同风格的面板
- 麦克风 / 音箱分区展示，当前默认设备带 ✓ 标记，点击即切换
- 底部提供"打开主窗口"和"退出"
- 点击面板外任意位置自动收起

### 设置选项
- **关闭行为**：询问/最小化到托盘/直接退出
- **主题模式**：浅色/深色/跟随系统
- **设备显示范围**：智能/全部/仅 USB 和蓝牙
- **快捷键设置**：自定义切换快捷键
- **开机自启动**：开关
